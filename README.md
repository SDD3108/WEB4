# WEB4
Assignment 4 for Web Technologies
Student: Satimov Damir  
Group: SE-2525

A five-page form project made with HTML, Tailwind CSS and JavaScript Task 0 and Task 1 use plain HTML without CSS Tasks 2–4 use Tailwind CSS through the browser CDN in place of Bootstrap

## Pages

- `indexhtml` — Task 0: basic contact form
- `html5-validationhtml` — Task 1: built-in HTML5 validation
- `tailwind-formhtml` — Task 2: responsive contact form with Tailwind
- `tailwind-validationhtml` — Task 3: valid and invalid feedback
- `registrationhtml` — Task 4: registration form with password confirmation

Passwords require at least 8 characters, one uppercase letter, one lowercase letter, one number and one special character Spaces are not allowed Hobbies are optional

Forms are demonstrations No messages are sent, no accounts are created, and no entered data is stored

## Run locally

Extract the ZIP and open `indexhtml` in a browser, or open the folder in VS Code and use Live Server No installation or build is needed An internet connection is required for the Tailwind CDN on Tasks 2–4

## Publish on GitHub Pages

1 Upload the contents of the `WEB4` folder to the root of the `SDD3108/WEB4` repository Keep the `js` folder and its file together The root must contain `indexhtml`
2 Open repository Settings → Pages
3 Under Build and deployment, choose Deploy from a branch
4 Choose `main` and `/ (root)`, then save
5 Wait for deployment and open the website URL shown by GitHub Pages
